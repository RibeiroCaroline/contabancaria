# 🏦 Conta Bancária 🏦

 📚 Este é um projeto de simulação de uma conta bancária desenvolvido para fins de aprendizado e prática em Java. O sistema permite operações básicas como cadastro de conta, depósito, saque e transferência de valores. 📚

## ⚒️ Tecnologias Utilizadas

- **Java**

## Funcionalidades

💵 Cadastro de conta bancária  
💵 Consulta de saldo  
💵 Realização de depósitos  
💵 Saques  
💵Transferências entre contas  

## Como Executar o Projeto

### 1. Clonar o Repositório
```bash
git clone https://github.com/RibeiroCaroline/contabancaria.git
```

### 2. Compilar e Executar o Projeto
- Navegue até o diretório do projeto e compile o código:

```bash
javac Menu.java
```

- Execute a aplicação:

```bash
java Menu
```
